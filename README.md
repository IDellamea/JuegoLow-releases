# JuegoLow — descargas

**[⬇ Descargar el instalador (JuegoLow_Setup.exe)](https://github.com/IDellamea/JuegoLow-releases/raw/main/JuegoLow_Setup.exe)**

1. Ejecutá `JuegoLow_Setup.exe`. Si Windows muestra "Windows protegió su PC": *Más información → Ejecutar de todas formas*.
2. Abrí **JuegoLow**, poné tu nombre y tocá **Unirse**.
3. El juego se actualiza solo cada vez que lo abrís.

Controles: clic izquierdo (o mantener) para caminar, rueda del mouse para zoom.

---
Este repo solo tiene las descargas. `latest.json` y `pck/` los usa el actualizador del juego.
